# FIPE API Java

Projeto em Java para consultar informações de veículos utilizando a API da Tabela FIPE.

A ideia é buscar os dados disponibilizados pela API, converter as respostas JSON em objetos Java e trabalhar com essas informações dentro da aplicação.

## Tecnologias

- Java
- Stream API
- Spring Boot
- Jackson
- API REST

## O que o projeto faz

- Busca dados na API da FIPE.
- Converte o JSON recebido em objetos Java.
- Permite trabalhar com as informações dos veículos retornados pela API.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/mimipub/fipe-api-java.git
   ```

2. Abra o projeto no IntelliJ IDEA.
3. Aguarde a configuração das dependências.
4. Execute a classe principal.

## O que estou praticando

Neste projeto, estou colocando em prática o consumo de APIs com Java, o uso do Jackson para trabalhar com JSON e a manipulação dos dados recebidos.
